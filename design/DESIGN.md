# Hustlrr website: design rules

The token sheet for the Hustlrr marketing site and blog and for `design/hustlrr-website.pen`. The front matter is
generated from what the pages render (`design/tools/pen-baseline/README.md`): capture a local build, run
`sync.sh`, and never hand-edit a value. Code wins ties: the `@theme` block in `src/styles/global.css` is the source.

## How the colours are split

- `colors:` holds exactly the hex `--color-*` entries of the site's `@theme` (rendered or not), so
  `hq design tokens-check ai-guru-website` compares them both ways and exits 0.
- `colorsExtra:` holds every other colour the pages render: Tailwind's built-in palette (`white`, `black`,
  `green-400`, `red-400`, `gray-100`), `text-secondary` (an `rgba()` in `@theme`, which the checker can't read),
  and 18 `literal-*` colours with no token (mostly white at 2–80% alpha for glass and borders). Pen binds both.

## What the code defines

- `@theme` in `src/styles/global.css`: backgrounds (`bg-primary` #0A0C16, `bg-secondary`, `bg-card`,
  `bg-card-hover`), `accent` #5E6CFF with `accent-light` / `accent-dark`, text (`text-primary`, `text-secondary`,
  `text-muted`), `border` / `border-strong`, a type scale (`--text-hero-brand` … `--text-xs`), `--spacing-section`
  / `--spacing-block`, radii (`card` 16, `button` 8, `cta` 37, `badge` 16, `section` 24, `pill`), content widths
  and motion (`ease-smooth`, `ease-bounce`, `duration-fast/base/slow`).
- Type: Inter 4 (self-hosted `public/fonts/Inter-Variable.woff2`), weights 400–700. Inter has an optical-size axis
  that Chrome sets per size, so the Pen file uses instances `Inter 14` … `Inter 32` made locally by
  `design/fonts/make-opsz.sh` from the site's own file (gitignored).
- One scheme: the palette is dark and there is no light mode.

## Principles (read from the CSS)

- Deep navy ground, white text at a few opacities, one indigo accent (`accent`) for primary actions and highlights.
- Cards on `bg-card` with hairline `border` and large radii; glassy pills for navigation.
- Pill and `cta` (37 px) radii for buttons; motion is short and eased (`duration-base` 0.2 s, `ease-smooth`).

## Not in the Pen file

- `/de/`: the same pages with translated copy. Blog posts share one template (one post captured).
- Hover/focus states, the open mobile menu, animated gradients.

## Open questions

- Radius and type tokens share values with Tailwind's defaults, and the draft names a few after the Tailwind token
  (`rounded-2xl` is 16 px, the same as `--radius-card`). Rename in DESIGN.md to the site's own names?
- 18 `literal-*` colours: promote the white-alpha set (white at 2, 10, 20, 30, 60, 70 and 80%) to tokens?
- 43 spacing values across two widths: is a fixed scale wanted?

## Anti-defaults (avoid in every design)

- Purple-to-blue gradient wallpapers, neon glows, more than one accent.
- Stock AI imagery (robots, brains); show the real app.
