# hustlrr.ai

Marketing site for [Hustlrr](https://www.hustlrr.ai), built with Astro 5 and Tailwind CSS v4 in English and German. It deploys to GitHub Pages on every merge to `main`.

```sh
npm ci
npm run dev          # http://localhost:4321
npm run verify       # typecheck + unit tests + build
npm run test:e2e     # Playwright, mobile/tablet/desktop
```

Conventions, project layout, and the EN/DE parity rules are in [AGENTS.md](AGENTS.md). Humans and coding agents both work from it.
